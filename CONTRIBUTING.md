## Quick Setup


Clone the repository:

```bash
git clone https://github.com/Ozag-Labs/SecureGitX.git
cd SecureGitX
````

Create a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

Install development dependencies:

```bash
pip install -e ".[dev]"
```
